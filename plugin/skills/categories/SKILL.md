---
name: categories
description: See, add, or remove the user's Clyde categories, including ready-made ones from Enhance.
---

Show the user's categories with `show_categories`. Add or remove a category, or bring one in from Enhance, with `edit`. A category's name and place are part of it, so a new name or place is a new category: add it, then remove the old one, moving its transactions to the new one.

A name or a root (such as "business") the user gives narrows the categories shown, or says which one to change. With no category named for a change, show the categories to pick from. When a category to remove has transactions, ask the user which category takes them.
