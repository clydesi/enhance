---
name: import-file
description: Bring transactions into Clyde from a file, such as a statement, an export, a screenshot, or pasted text, and check how the import went.
---

Turn the user's file into a Clyde import file (`describe` topic imports) and send it with `import`. Check how it went with `show_imports`.

An account the user names is where the transactions go. With no file given, ask for one.
