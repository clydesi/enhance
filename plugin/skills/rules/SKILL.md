---
name: rules
description: See, add, change, run, or remove the user's Clyde rules, ready-made Enhance ones too, each setting the payee and category of matching transactions, such as "my gym's charges are Fitness > Gym".
---

Show the user's rules with `show_rules`, and add, change, run, or remove one with `edit`.

Browse ready-made Enhance rules with the `enhance_rules` recipe in `query`, and add the user's picks with `edit`. Once the user agrees, set a rule to run on its own or run it once on existing transactions.

What the user says a rule does gives its match and what it sets; ask for any missing part. With no rule named for a change, show the rules to pick from.
